# CHANGE.md

Changelog for this repo (`simplemotion/sm-install-ext`).

This repo serves the external installer site at install.simplemotion.com. It holds no source: `simplemotion/sm-install-int` deploys the site to the `gh-pages` branch. The CHANGE.md of `sm-install-int` records the changes to the installers.
